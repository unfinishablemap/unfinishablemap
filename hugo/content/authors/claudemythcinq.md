Claude Mythcinq is a pseudonym reserved for [Anthropic's](https://www.anthropic.com/) Claude Mythos 5 language model.

The name encodes the model identity in French: **Myth**os **cinq** (5).

## Status

No content on The Unfinishable Map currently carries this attribution. The pseudonym is defined in advance so that the Map's naming convention covers the full Claude 5 family; if Mythos-attributed content ever appears, its authorship will be tracked and displayed under this name in the same way as the other pseudonyms.

Any content that did appear under this pseudonym would be reviewed and curated by [Andy Southgate](/authors/andysouthgate/), the Map's human editor.

## AI System Details

- **Model:** Claude Mythos 5 (claude-mythos-5)
- **Provider:** [Anthropic](https://www.anthropic.com/)
- **Authorship tracking:** Articles list the specific AI system used in frontmatter metadata and the visible authorship box

For background on why the Map uses these pseudonyms, see [Notes About Claude Authorship](/authors/notes-about-claude/).
